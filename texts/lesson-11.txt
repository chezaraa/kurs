ОСНОВАНИЕ ПОЛА, ПАРКЕТ, ЛАМИНАТ И ВИНИЛ

Продолжительность основной практики: 60 минут. Уровень: с нуля, с профессиональными речевыми формулами.

РЕЗУЛЬТАТ
Обсудить состояние основания, выравнивание, влажность, высоты, стыки, плавающую и клеевую укладку, плинтусы и
переходы. Объяснить ограничения материалов без универсальных обещаний «завтра можно укладывать».

КАК ИСПОЛЬЗОВАТЬ УРОК
Это практический испанский Испании для ремонта квартир: Барселона, Таррагона и Costa Dorada. Ситуации адаптированы
к предоставленной презентации INKCRAFT: исполнение проектов дизайнеров, координация восьми направлений работ, кухни
и ванные, индивидуальные детали, связь с заказчиком.
Говори вслух. В каждом новом уроке активно отработай примерно 5-6 глаголов и 10-12 терминов, остальные сначала
узнавай по смыслу. Готовые более сложные фразы можно использовать целиком до изучения их грамматики. Обращение
tú/usted сохраняй последовательно; в учебных ситуациях специально показаны оба варианта.
Основная часовая программа — разделы 1-8. В вопросах заказчика за этот час обязательны первые четыре пары;
остальные добавлены для рабочего справочника. Словари в конце расширяют охват и не требуют заучивания за один час.
Ответы открывай после самостоятельной попытки.
Примеры размеров, денег, календаря и объектов учебные, если прямо не указано иное. Это языковой курс: техническое
решение подтверждают проект, данные изготовителя, обследование и соответствующий специалист. Реальные сообщения из
примеров автоматически не отправляются.

1. РАЗМИНКА И ПОВТОРЕНИЕ | 00-05 МИН
Скажи: «Срок зависит от системы»; «Это другой материал»; «Что хотите сохранить?». Ключ: El plazo depende del
sistema. Es otro material. ¿Qué quiere mantener?

2. КОРОТКАЯ ЯЗЫКОВАЯ СХЕМА | 05-15 МИН
Действие в процессе: estar + gerundio. Estamos preparando el soporte — мы сейчас готовим основание. Estoy midiendo
— я измеряю. Está secando — сохнет.
Обычно -ar → -ando: preparar → preparando; -er/-ir → -iendo: recibir → recibiendo. Некоторые формы неправильные;
здесь выучи medir → midiendo, seguir → siguiendo.
Разница: preparamos el suelo — готовим пол как этап/обычное действие; estamos preparando el suelo — сейчас идёт
подготовка. Не используй estoy preparar.
Ya — уже; todavía — ещё; todavía no — ещё не. El soporte todavía no está listo. — Основание ещё не готово. Ya está
nivelado — уже выровнено. Это состояние, а не подробный отчёт о прошлом.
Hasta + существительное/время: hasta la comprobación — до проверки; hasta el lunes — до понедельника. Рабочая фраза
без новой грамматики: No colocamos el suelo antes de comprobar el soporte.
Толщина: quince milímetros — 15 мм; altura final — итоговая отметка; diferencia de nivel — перепад. Capa — слой;
capa fina/gruesa — тонкий/толстый слой.
Не смешивай материал и способ: parquet multicapa — многослойная паркетная доска; tarima maciza — массивная доска;
colocación flotante — плавающая укладка; colocación encolada — приклеенная укладка. Слово flotante само по себе не
определяет материал.

3. ГЛАГОЛЫ, ТЕРМИНЫ И ОПОРНЫЕ ФРАЗЫ | 15-25 МИН
Глаголы. Если дана тройка форм, порядок: я / Вы (один человек) / мы. Частотные отдельные формы подписаны.
nivelar — выравнивать по уровню; nivelo / nivela / nivelamos.
alisar — сглаживать; aliso / alisa / alisamos.
lijar — шлифовать; lijo / lija / lijamos.
pegar — приклеивать; pego / pega / pegamos.
secar — сохнуть/сушить; seco / seca / secamos.
esperar — ждать; espero / espera / esperamos.
encajar — соединять/подгонять; encajo / encaja / encajamos.
comprobar — проверять; compruebo / comprueba / comprobamos.

Термины:
el soporte — основание; la solera — бетонное основание/плита пола по конструкции.
el recrecido — дополнительный слой/стяжка; la pasta autonivelante — самонивелирующаяся смесь.
la planeidad — плоскостность; el desnivel — перепад; la humedad residual — остаточная влажность.
el parquet multicapa — многослойная паркетная доска; la tarima maciza — массивная доска.
el laminado — ламинат; el suelo vinílico — виниловое покрытие; el vinilo rígido SPC — жёсткий винил SPC.
la base / la manta — подложка по контексту; la barrera de vapor — пароизоляция.
la colocación flotante — плавающая укладка; la colocación encolada — клеевая.
el rodapié — плинтус; el perfil de transición — переходный профиль; la junta perimetral — периметральный зазор/шов.

Рабочие фразы:
Estamos comprobando la humedad y la planeidad. — Проверяем влажность и плоскостность.
El soporte todavía no está listo para colocar. — Основание ещё не готово к укладке.
Hay que definir la altura final con puertas y otros pavimentos. — Нужно согласовать отметку пола с дверями и
другими покрытиями.
Este producto no resuelve por sí solo cualquier grieta o desnivel. — Один этот материал не устраняет любую трещину
или перепад.
La base debe ser compatible con el suelo elegido. — Подложка должна быть совместима с покрытием.
Vamos a confirmar el sistema de colocación con la ficha del fabricante. — Подтвердим систему укладки по
документации изготовителя.
¿Quiere conservar los rodapiés? — Хотите сохранить плинтусы?
La junta se resuelve con el detalle previsto. — Шов выполняем по предусмотренному узлу.
No tapamos un problema activo de humedad o plagas con el suelo nuevo. — Не закрываем новым полом действующую
проблему сырости или вредителей.
La compatibilidad con suelo radiante se comprueba para el sistema completo. — Совместимость с тёплым полом
проверяется для всей системы.

4. УСТНАЯ ТРЕНИРОВКА | 25-35 МИН
Опиши пять текущих действий: estamos midiendo / nivelando / lijando / colocando / comprobando. Затем отрицай
готовность: todavía no está seco / listo / aprobado.
Сравни tres capas: soporte, base, pavimento. Назови материал и способ отдельно для parquet, laminado, vinilo.
Прочитай толщины: 2 mm, 5 mm, 15 mm, 25 mm. Ключ: dos, cinco, quince, veinticinco milímetros. Итоговую высоту
всегда выражай отдельной фразой: La altura final es…

5. РАЗГОВОР С ЗАКАЗЧИКОМ | 35-45 МИН
Вопросы заказчика и возможные ответы. Первые четыре пары — активная практика, остальные — расширенный банк.
1. ¿Podemos poner el suelo mañana? — Можно завтра укладывать пол?
Depende del producto aplicado, las condiciones y las comprobaciones del soporte. — Зависит от материала, условий и
проверок основания.
2. ¿El vinilo no necesita nivelar? — Под винил не нужно выравнивать?
También necesita un soporte adecuado; comprobamos las tolerancias del sistema elegido. — Ему тоже нужно подходящее
основание; проверим допуски выбранной системы.
3. ¿Se puede poner todo sin perfiles en las puertas? — Можно везде без профилей в дверях?
Revisamos superficies, pasos, juntas y condiciones del fabricante antes de confirmarlo. — До подтверждения проверим
площади, переходы, швы и условия изготовителя.
4. ¿La madera va a moverse? — Дерево будет двигаться?
La madera responde a las condiciones ambientales; elegimos el sistema y el mantenimiento adecuados. — Дерево
реагирует на условия среды; подбираем систему и уход.
5. ¿Qué hacemos si había termitas? — Что делать, если были термиты?
Antes de cerrar, confirmamos el estado del problema y la intervención necesaria con una empresa especializada. — До
закрытия проверим состояние проблемы и нужную обработку со специализированной компанией.
6. ¿Hay que cortar las puertas? — Нужно подрезать двери?
Lo comprobamos con la altura final de todas las capas y los encuentros. — Проверим по итоговой высоте всех слоёв и
примыканиям.

Диалог. Прочитай в двух ролях, затем повтори с изменёнными предметами и условиями:
Заказчик: Quiero parquet multicapa de quince milímetros. — Хочу паркетную доску 15 мм.
Сергей: ¿Prefiere colocación flotante o encolada? — Предпочитаете плавающую или клеевую укладку?
Заказчик: Flotante. ¿Podemos aprovechar la base? — Плавающую. Можно оставить подложку/основание? Здесь нужно
уточнить значение base.
Сергей: ¿Se refiere a la manta o al soporte? Primero comprobamos los dos. — Вы про подложку или основание? Сначала
проверим оба.
Заказчик: Hay grietas, pero no se mueve. — Есть трещины, но не двигается.
Сергей: Revisamos su estado y definimos la preparación compatible con el sistema. — Проверим состояние и определим
подготовку под систему.
Заказчик: ¿Cuándo se puede colocar? — Когда можно укладывать?
Сергей: Lo confirmamos después de las comprobaciones y de revisar los plazos de los productos. — Подтвердим после
проверок и уточнения сроков материалов.

6. РОЛЕВОЙ СЦЕНАРИЙ И ПИСЬМЕННОЕ ПОДТВЕРЖДЕНИЕ | 45-55 МИН
Квартира с четырьмя комнатами, разными основаниями и переходами. Клиент хочет деревянный пол без задержек и без
видимых переходных профилей. Уточни влажность, систему, высоты, двери и швы по документации. Объясни, что сроки
связаны с готовностью основания, и согласуй, какие данные ещё нужны. Не назначай проценты влажности или миллиметры
допусков как общие для всех покрытий.

Пример письменного подтверждения. Сначала пойми, затем перескажи своими словами:
Hola. Estamos revisando la planeidad, la humedad y las alturas del soporte. Antes de confirmar la fecha de
colocación necesitamos cerrar el sistema de suelo y comprobar su documentación. Te indicamos por separado la
preparación, la base, el pavimento y los remates.
Здравствуйте. Проверяем плоскостность, влажность и высоты основания. До подтверждения даты укладки нужно определить
систему пола и проверить документацию. Отдельно укажем подготовку, подложку, покрытие и примыкания.

7. КОНТРОЛЬ БЕЗ ПОДСКАЗКИ | 55-60 МИН
1. Мы сейчас проверяем влажность.
2. Основание ещё не готово.
3. Это паркетная доска, укладка плавающая.
4. Хотите сохранить плинтусы?
5. Нужно подтвердить итоговую высоту.
6. До проверки основания пол не укладываем.
7. Нужно подрезать двери?
8. Срок зависит от выбранной системы.

8. КЛЮЧИ К КОНТРОЛЮ | ОТКРЫТЬ ПОСЛЕ ПОПЫТКИ
1. Estamos comprobando la humedad.
2. El soporte todavía no está listo.
3. Es parquet multicapa con colocación flotante.
4. ¿Quiere conservar los rodapiés?
5. Hay que confirmar la altura final.
6. No colocamos el suelo antes de comprobar el soporte.
7. ¿Hay que cortar las puertas?
8. El plazo depende del sistema elegido.

ПРОВЕРКА РЕЗУЛЬТАТА
Рабочая цель: 7 из 8 контрольных фраз без таблицы и понятный разговор по сценарию. Допустимы другие грамматически
правильные ответы с тем же смыслом. Вопрос, отрицание, участник и технический предмет должны совпадать с заданием.
При ошибке произнеси правильное предложение целиком. Итоговая оценка урока 16 дополнена собственной шкалой в
сценарии.

ПОВТОРЕНИЕ МЕЖДУ ЗАНЯТИЯМИ | 10 МИНУТ
3 минуты: три глагола в формах «я / мы / мы не / Вы...?». 4 минуты: диалог в двух ролях с заменой двух предметов. 3
минуты: объясни реальную или учебную ситуацию на объекте пятью фразами. Для прошлых событий используй прошедшие
формы после урока 14; до этого тренируй учебные ситуации в настоящем. Это дополнительное закрепление сверх 16
учебных часов.

СПРАВОЧНИК ПО ТЕМЕ | ДЛЯ ПОИСКА НА ОБЪЕКТЕ
Материалы/узлы: el mortero de reparación — ремонтный раствор; la imprimación de adherencia — адгезионная грунтовка;
la resina — смола; la resina epoxi — эпоксидная смола; la malla de refuerzo — армирующая сетка; la capa de
regularización — выравнивающий слой; la lámina acústica — акустическая подложка/мембрана; el adhesivo para parquet
— паркетный клей; el machihembrado — шпунтовое соединение; el sistema clic — замковое соединение; la junta de
dilatación — деформационный шов; la junta de separación — разделительный шов; el remate — примыкание/завершение; la
transición — переход; el umbral — порог; el zócalo — цоколь/плинтус по контексту; la moqueta — ковролин; el linóleo
— линолеум, не общее название любого винила; el terrazo — терраццо; el microcemento — микроцемент; el pavimento
continuo — бесшовное покрытие; el acabado aceitado — масляная отделка; el acabado barnizado — лакированная отделка;
el barniz — лак; el aceite — масло; el acuchillado — циклёвка; la aclimatación — выдержка материала в условиях
помещения.
Инструменты: la regla de dos metros — двухметровое правило; la galga — щуп; el medidor de humedad — влагомер; la
sierra de inglete — торцовочная пила; la espátula dentada — зубчатый шпатель; el taco de golpeo — подбивочный
брусок; las cuñas de separación — распорные клинья; el rodillo de presión — прикаточный валик.
Глаголы-справка: regularizar — выравнивать; reparar — ремонтировать; imprimar — грунтовать; extender —
распределять; verter — выливать; adherir — приклеивать; aclimatar — выдерживать для адаптации; dilatarse —
расширяться; contraerse — сжиматься; crujir — скрипеть; levantarse — подниматься/вздуваться; barnizar — лакировать;
aceitar — обрабатывать маслом; acuchillar — циклевать.
