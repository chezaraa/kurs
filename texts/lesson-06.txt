INKCRAFT | ИСПАНСКИЙ ДЛЯ РЕМОНТА | УРОК 06 ИЗ 16

ДЕМОНТАЖ, КЛАДКА, ПРОЁМЫ И СТРОИТЕЛЬНЫЙ МУСОР

Продолжительность основной практики: 60 минут. Уровень: с нуля, с профессиональными речевыми формулами.

РЕЗУЛЬТАТ
Объяснить объём демонтажа, разницу между снятием оборудования и сносом перегородки, сохранение элементов,
кладку/заделку, штробы, вывоз отходов и остановку работ при непредвиденном основании.

КАК ИСПОЛЬЗОВАТЬ УРОК
Это практический испанский Испании для ремонта квартир: Барселона, Таррагона и Costa Dorada. Ситуации адаптированы
к предоставленной презентации INKCRAFT: исполнение проектов дизайнеров, координация восьми направлений работ, кухни
и ванные, индивидуальные детали, связь с заказчиком.
Говори вслух. В каждом новом уроке активно отработай примерно 5-6 глаголов и 10-12 терминов, остальные сначала
узнавай по смыслу. Готовые более сложные фразы можно использовать целиком до изучения их грамматики. Обращение
tú/usted сохраняй последовательно; в учебных ситуациях специально показаны оба варианта.
Основная часовая программа — разделы 1-8. В вопросах заказчика за этот час обязательны первые четыре пары;
остальные добавлены для рабочего справочника. Словари в конце расширяют охват и не требуют заучивания за один час.
Ответы открывай после самостоятельной попытки.
Примеры размеров, денег, календаря и объектов учебные, если прямо не указано иное. Это языковой курс: техническое
решение подтверждают проект, данные изготовителя, обследование и соответствующий специалист. Реальные сообщения из
примеров автоматически не отправляются.

1. РАЗМИНКА И ПОВТОРЕНИЕ | 00-05 МИН
Скажи: «Сначала защищаем общие зоны»; «Нам нужен доступ»; «Начнём после поставки». Ключ: Primero protegemos las
zonas comunes. Necesitamos acceso. Vamos a empezar después de la entrega.

2. КОРОТКАЯ ЯЗЫКОВАЯ СХЕМА | 05-15 МИН
Короткие дополнения lo / la / los / las заменяют уже названный предмет.
El mueble: lo desmontamos — его демонтируем. La puerta: la conservamos — её сохраняем. Los azulejos: los retiramos
— их снимаем. Las tuberías: las cambiamos — их меняем.
Местоимение обычно перед личным глаголом: no lo retiramos. С инфинитивом возможны два варианта: lo vamos a retirar
/ vamos a retirarlo — будем это снимать. Тренируй первый вариант.
Не заменяй местоимение по русскому роду: la pared → la, хотя по-русски стена тоже женского рода; el suelo → lo,
хотя «покрытие» среднего рода. Смотри на испанское слово.
Hay que + инфинитив — нужно сделать: hay que proteger el suelo — нужно защитить пол. Не указывает исполнителя.
Tenemos que — нужно именно нам.
Se puede + инфинитив — можно/допустимо: se puede conservar. No se puede + инфинитив — нельзя/невозможно. Эти
формулы не заменяют проверку технической возможности.
Различай desmontar (разобрать/демонтировать оборудование), retirar (снять/удалить/вывезти), demoler/derribar
(разрушить/снести), picar (сбить/выдолбить), rozar/hacer rozas (штробить). Кухонный шкаф обычно desmontamos, старую
облицовку retiramos/picamos, перегородку derribamos при согласованном решении.

3. ГЛАГОЛЫ, ТЕРМИНЫ И ОПОРНЫЕ ФРАЗЫ | 15-25 МИН
Глаголы. Если дана тройка форм, порядок: я / Вы (один человек) / мы. Частотные отдельные формы подписаны.
retirar — снимать/удалять; retiro / retira / retiramos.
derribar — сносить; derribo / derriba / derribamos.
demoler — разрушать; demuelo / demuele / demolemos.
picar — сбивать/долбить; pico / pica / picamos.
conservar — сохранять; conservo / conserva / conservamos.
levantar — возводить/поднимать/вскрывать по контексту; levanto / levanta / levantamos.
abrir — открывать; abro / abre / abrimos.
cerrar — закрывать; cierro / cierra / cerramos.

Термины:
el desmontaje — демонтаж поэлементно; la demolición — разрушение/снос.
el tabique — перегородка; el muro de carga — несущая стена.
la roza — штроба; el hueco — проём; el dintel — перемычка.
el ladrillo — кирпич; el bloque — блок; el mortero — раствор.
el recrecido — выравнивающий/поднимающий слой; el enfoscado — цементное оштукатуривание.
los escombros — строительный мусор; el saco de escombros — мешок мусора.
el contenedor — контейнер; el gestor autorizado — уполномоченный оператор отходов.
la cata — локальное вскрытие для обследования; la instalación oculta — скрытая коммуникация.

Рабочие фразы:
Esta puerta se conserva. — Эту дверь сохраняем.
El mueble lo desmontamos sin romperlo. — Мебель разбираем без разрушения.
Primero comprobamos las instalaciones ocultas. — Сначала проверяем скрытые коммуникации.
Hay que abrir una cata para ver el soporte. — Нужно сделать локальное вскрытие и увидеть основание.
No confirmamos el derribo hasta revisar la solución técnica. — Не подтверждаем снос до проверки технического
решения.
Vamos a hacer las rozas según el plano. — Выполним штробы по плану.
Después cerramos las rozas y regularizamos la superficie. — Затем заделаем штробы и выровняем поверхность.
La retirada de escombros se organiza con un gestor autorizado. — Вывоз отходов организуем через уполномоченного
оператора.
Este elemento no estaba visible en la visita inicial. — Этот элемент не был виден при первом осмотре.
Paramos esta zona y consultamos antes de continuar. — Останавливаем эту зону и уточняем решение до продолжения.

4. УСТНАЯ ТРЕНИРОВКА | 25-35 МИН
Замени предмет местоимением: conservamos la puerta → la conservamos; retiramos los azulejos → los retiramos;
desmontamos el mueble → lo desmontamos; cambiamos las tuberías → las cambiamos.
Построй hay que + proteger / comprobar / retirar / cerrar. Затем no se puede + continuar / demoler / tapar.
Уточни действие: «снимаем шкаф», «сбиваем плитку», «делаем штробу», «заделываем проём», «возводим перегородку».
Один допустимый набор: desmontamos el armario; picamos los azulejos; hacemos una roza; cerramos el hueco;
levantamos un tabique.

5. РАЗГОВОР С ЗАКАЗЧИКОМ | 35-45 МИН
Вопросы заказчика и возможные ответы. Первые четыре пары — активная практика, остальные — расширенный банк.
1. ¿Se puede tirar esta pared? — Можно снести эту стену?
Primero confirmamos si es un tabique o un elemento estructural y revisamos proyecto y trámite. — Сначала определим,
перегородка это или конструктивный элемент, и проверим проект и оформление.
2. ¿Puede guardar la puerta para reutilizarla? — Можно сохранить дверь для повторного использования?
Sí, la desmontamos y la protegemos; revisamos antes su estado. — Да, снимем и защитим, предварительно проверив
состояние.
3. ¿Por qué hay que abrir aquí? — Зачем здесь вскрывать?
Necesitamos comprobar el soporte y la instalación que queda oculta. — Нужно проверить основание и скрытую
коммуникацию.
4. ¿El escombro está incluido? — Вывоз мусора включён?
La retirada prevista aparece en esta partida; si cambia el volumen, lo revisamos antes. — Предусмотренный вывоз
указан в этой позиции; изменение объёма согласуем заранее.
5. ¿Y si aparece amianto? — А если обнаружится асбест?
No seguimos manipulando el material sospechoso; lo valoramos con una empresa especializada. — Не продолжаем работу
с подозрительным материалом; обращаемся к специализированной компании.
6. ¿Puede abrir un hueco más grande? — Можно увеличить проём?
Hay que comprobar el elemento y definir la solución y la documentación necesarias. — Нужно проверить элемент и
определить решение и необходимые документы.

Диалог. Прочитай в двух ролях, затем повтори с изменёнными предметами и условиями:
Заказчик: Quiero conservar esta puerta. — Хочу сохранить эту дверь.
Сергей: De acuerdo, la desmontamos y la protegemos. — Хорошо, снимем и защитим.
Заказчик: Esta pared la quitamos toda. — Эту стену убираем полностью.
Сергей: Primero revisamos si afecta a la estructura o a alguna instalación. — Сначала проверим влияние на
конструкцию и коммуникации.
Заказчик: ¿Entonces no puede empezar hoy? — Значит, сегодня начать нельзя?
Сергей: Podemos preparar la zona y retirar los elementos ya confirmados. — Можем подготовить зону и снять уже
согласованные элементы.
Заказчик: ¿Qué falta para esta pared? — Чего не хватает по стене?
Сергей: La comprobación técnica y la confirmación del alcance y del trámite. — Технической проверки и подтверждения
состава работ и оформления.

6. РОЛЕВОЙ СЦЕНАРИЙ И ПИСЬМЕННОЕ ПОДТВЕРЖДЕНИЕ | 45-55 МИН
Разборка старой кухни: сохранить дверь, убрать шкафы и плитку, сделать штробы, вывезти мусор. За облицовкой
обнаружена труба, которой нет в плане. Объясни заказчику, какие работы продолжаются, какая зона приостановлена и
что надо уточнить. Дополнительный сценарий: подозрение на несущий элемент. Не ставь диагноз по одной фотографии.

Пример письменного подтверждения. Сначала пойми, затем перескажи своими словами:
Hola. Hemos retirado los muebles previstos y protegido la puerta que vamos a conservar. Al abrir la pared ha
aparecido una tubería no indicada en el plano. Esta zona queda pendiente de revisión. Te enviamos fotos y la
propuesta antes de continuar.
Здравствуйте. Сняли предусмотренную мебель и защитили сохраняемую дверь. При вскрытии появилась труба, не указанная
на плане. Эта зона ожидает проверки. До продолжения отправим фотографии и предложение.

7. КОНТРОЛЬ БЕЗ ПОДСКАЗКИ | 55-60 МИН
1. Эту дверь сохраняем: замените предмет местоимением.
2. Нужно проверить скрытые коммуникации.
3. Сначала защищаем пол.
4. Затем заделываем штробы.
5. Можно сохранить шкаф?
6. Снос пока не подтверждён.
7. Вывоз мусора указан отдельной позицией.
8. До продолжения уточним решение.

8. КЛЮЧИ К КОНТРОЛЮ | ОТКРЫТЬ ПОСЛЕ ПОПЫТКИ
1. La conservamos.
2. Hay que comprobar las instalaciones ocultas.
3. Primero protegemos el suelo.
4. Después cerramos las rozas.
5. ¿Se puede conservar el armario?
6. El derribo todavía no está confirmado.
7. La retirada de escombros aparece en una partida aparte.
8. Consultamos la solución antes de continuar.

ПРОВЕРКА РЕЗУЛЬТАТА
Рабочая цель: 7 из 8 контрольных фраз без таблицы и понятный разговор по сценарию. Допустимы другие грамматически
правильные ответы с тем же смыслом. Вопрос, отрицание, участник и технический предмет должны совпадать с заданием.
При ошибке произнеси правильное предложение целиком. Итоговая оценка урока 16 дополнена собственной шкалой в
сценарии.

ПОВТОРЕНИЕ МЕЖДУ ЗАНЯТИЯМИ | 10 МИНУТ
3 минуты: три глагола в формах «я / мы / мы не / Вы...?». 4 минуты: диалог в двух ролях с заменой двух предметов. 3
минуты: объясни реальную или учебную ситуацию на объекте пятью фразами. Для прошлых событий используй прошедшие
формы после урока 14; до этого тренируй учебные ситуации в настоящем. Это дополнительное закрепление сверх 16
учебных часов.

СПРАВОЧНИК ПО ТЕМЕ | ДЛЯ ПОИСКА НА ОБЪЕКТЕ
Кладка/основание: el cemento — цемент; la arena — песок; la cal — известь; el hormigón — бетон; el hormigón armado
— железобетон; la armadura — арматура; la malla — сетка; el mallazo — арматурная сетка; el anclaje —
анкер/крепление; el encofrado — опалубка; la junta — шов; el refuerzo — усиление; el apoyo — опора/опирание; el
apuntalamiento — временное подпирание; el zuncho — обвязочный пояс; el dintel — перемычка; la fábrica de ladrillo —
кирпичная кладка; el bloque de hormigón — бетонный блок; el hormigón celular — газобетон; el cascote — обломки
кладки; el relleno — заполнение.
Оснастка: la paleta — кельма; la llana — гладилка; el capazo — строительная гибкая ёмкость; el cubo — ведро; la
carretilla — тачка; la pala — лопата; el cortafríos — зубило; el saco — мешок; el big bag — большой мешок для
отходов.
Глаголы-справка: rozar — штробить; perforar — сверлить/пробивать; taladrar — сверлить; cortar — резать/отключать по
контексту; romper — ломать; apuntalar — подпирать; reforzar — усиливать; rellenar — заполнять; enfoscar —
штукатурить цементным раствором; regularizar — выравнивать; evacuar — отводить/вывозить; reutilizar — использовать
повторно; clasificar — сортировать.
Лексика описывает работу, но не задаёт порядок вмешательства в несущие конструкции или обращения с опасными
отходами.
