INKCRAFT | ИСПАНСКИЙ ДЛЯ РЕМОНТА | УРОК 03 ИЗ 16

ПРОЕКТ, ПЛАНИРОВКА И РАБОТА С ДИЗАЙНЕРОМ

Продолжительность основной практики: 60 минут. Уровень: с нуля, с профессиональными речевыми формулами.

РЕЗУЛЬТАТ
Читать и уточнять проект, обсуждать планировку и визуализации, согласовывать материалы и изменения с дизайнером.
Использовать ситуации из портфолио: от 3D до готового интерьера, скрытый свет, ниши, молдинги и единый
ответственный.

КАК ИСПОЛЬЗОВАТЬ УРОК
Это практический испанский Испании для ремонта квартир: Барселона, Таррагона и Costa Dorada. Ситуации адаптированы
к предоставленной презентации INKCRAFT: исполнение проектов дизайнеров, координация восьми направлений работ, кухни
и ванные, индивидуальные детали, связь с заказчиком.
Говори вслух. В каждом новом уроке активно отработай примерно 5-6 глаголов и 10-12 терминов, остальные сначала
узнавай по смыслу. Готовые более сложные фразы можно использовать целиком до изучения их грамматики. Обращение
tú/usted сохраняй последовательно; в учебных ситуациях специально показаны оба варианта.
Основная часовая программа — разделы 1-8. В вопросах заказчика за этот час обязательны первые четыре пары;
остальные добавлены для рабочего справочника. Словари в конце расширяют охват и не требуют заучивания за один час.
Ответы открывай после самостоятельной попытки.
Примеры размеров, денег, календаря и объектов учебные, если прямо не указано иное. Это языковой курс: техническое
решение подтверждают проект, данные изготовителя, обследование и соответствующий специалист. Реальные сообщения из
примеров автоматически не отправляются.

1. РАЗМИНКА И ПОВТОРЕНИЕ | 00-05 МИН
Скажи: «В этой стене есть трещина»; «Ширина комнаты три метра»; «Сначала проверяем». Ключ: Hay una grieta en esta
pared. La habitación mide tres metros de ancho. Primero comprobamos.

2. КОРОТКАЯ ЯЗЫКОВАЯ СХЕМА | 05-15 МИН
Querer + инфинитив — хотеть сделать: quiero cambiar — хочу поменять; quiere cambiar — Вы хотите поменять; queremos
cambiar — мы хотим поменять.
Poder + инфинитив — мочь: puedo / puede / podemos. Podemos mover la puerta — можем перенести дверь.
Necesitar + существительное или инфинитив: necesito el plano / necesitamos confirmar las medidas — нужен план /
нужно подтвердить размеры.
Не ставь два личных глагола подряд: queremos cambiar, а не queremos cambiamos.
Для желания заказчика: ¿Qué quiere mantener? — Что хотите сохранить? Для дизайнерского решения: ¿Dónde quiere
colocar la luz? — Где хотите разместить свет?
Este plano — этот план; esta pared — эта стена; estos planos — эти планы; estas medidas — эти размеры. Aquí / allí
— здесь / там.
Согласование: el plano actualizado — обновлённый план; la versión actualizada — обновлённая версия. Род слова
влияет на окончание прилагательного.
С дизайнером после перехода на tú: ¿Puedes confirmar esta medida? — Можешь подтвердить этот размер? С заказчиком на
usted: ¿Puede confirmar esta medida?
Готовая рабочая формула: No modificamos el proyecto sin aprobación. — Не изменяем проект без согласования. Наличие
дизайн-визуализации само по себе не означает, что весь комплект технических документов подготовлен; вопросы
документов тренируем в уроке 15.

3. ГЛАГОЛЫ, ТЕРМИНЫ И ОПОРНЫЕ ФРАЗЫ | 15-25 МИН
Глаголы. Если дана тройка форм, порядок: я / Вы (один человек) / мы. Частотные отдельные формы подписаны.
querer — хотеть; quiero / quiere / queremos.
poder — мочь; puedo / puede / podemos.
necesitar — нуждаться; necesito / necesita / necesitamos.
mantener — сохранять; mantengo / mantiene / mantenemos.
colocar — размещать; coloco / coloca / colocamos.
confirmar — подтверждать; confirmo / confirma / confirmamos.
respetar — соблюдать, уважать; respeto / respeta / respetamos.
modificar — изменять; modifico / modifica / modificamos.

Термины:
el plano — план/чертёж; la distribución — планировка.
el proyecto de interiorismo — дизайн-проект; el proyecto técnico — технический проект.
el render / la visualización 3D — визуализация; la axonometría — аксонометрия.
la memoria de calidades — описание материалов и качества отделки.
la medición — измерение; las mediciones — обмеры/ведомость объёмов по контексту; el replanteo — разметка на
объекте.
la cota — размерная отметка; la escala — масштаб; la sección — разрез.
el detalle constructivo — узел/конструктивная деталь; la aprobación — согласование.
la versión — версия; el cambio — изменение; el interlocutor único — единое контактное лицо.

Рабочие фразы:
Ejecutamos el proyecto del diseñador. — Выполняем проект дизайнера.
Respetamos el diseño y los materiales especificados. — Соблюдаем дизайн и указанные материалы.
Necesitamos el plano actualizado. — Нужен актуальный план.
¿Qué elementos quiere mantener? — Какие элементы хотите сохранить?
¿La medida está tomada desde el suelo terminado? — Размер взят от чистого пола?
Esta solución necesita un detalle constructivo. — Для этого решения нужен узел.
La imagen 3D no muestra esta instalación. — На 3D-изображении эта коммуникация не показана.
No cambiamos la distribución sin confirmación. — Не меняем планировку без подтверждения.
Primero hacemos el replanteo con el diseñador. — Сначала выполняем разметку с дизайнером.
Yo coordino los oficios y te informo de los cambios. — Я координирую специальности и сообщаю об изменениях;
обращение на tú.

4. УСТНАЯ ТРЕНИРОВКА | 25-35 МИН
Для «клиент / дизайнер / мы» строй: quiere / quiere / queremos + mantener, mover, cambiar, colocar. Пять предметов:
la puerta, el tabique, la luz, el lavabo, el mueble.
Преврати сообщение в вопрос: Necesitamos el plano. → ¿Necesitamos el plano? Затем уточни: ¿Qué plano necesitamos?
Сравни обращения: ¿Puedes confirmar la cota? → ¿Puede confirmar la cota? Не смешивай tú и usted в одной просьбе.
Повтори из урока 2: La puerta está aquí. El tabique es de ladrillo.

5. РАЗГОВОР С ЗАКАЗЧИКОМ | 35-45 МИН
Вопросы заказчика и возможные ответы. Первые четыре пары — активная практика, остальные — расширенный банк.
1. ¿Puede quedar igual que en el render? — Можно сделать как на визуализации?
Ese es el objetivo. Primero comprobamos medidas, materiales y detalles de ejecución. — Это наша цель. Сначала
проверяем размеры, материалы и узлы исполнения.
2. ¿Podemos mover esta pared? — Можно перенести эту стену?
Primero hay que confirmar qué tipo de pared es y revisar la solución técnica y el trámite. — Сначала нужно
определить тип стены и проверить техническое решение и оформление.
3. ¿Puede proponer otra distribución? — Можете предложить другую планировку?
Sí, podemos estudiar una alternativa y coordinarla con el diseñador. — Да, можем рассмотреть альтернативу и
согласовать её с дизайнером.
4. ¿Quién decide este cambio? — Кто принимает решение об изменении?
Lo confirmamos con el cliente y con el responsable del diseño antes de ejecutarlo. — До выполнения согласовываем с
заказчиком и ответственным за дизайн.
5. ¿El presupuesto incluye el diseño? — Дизайн входит в смету?
Lo indicamos por separado: diseño y ejecución son partidas distintas. — Указываем отдельно: дизайн и выполнение
работ — разные позиции.
6. ¿Tengo que hablar con todos los operarios? — Мне нужно общаться с каждым рабочим?
No hace falta. Yo soy tu interlocutor y coordino los oficios. — В этом нет необходимости. Я твоё контактное лицо и
координирую специалистов.

Диалог. Прочитай в двух ролях, затем повтори с изменёнными предметами и условиями:
Дизайнер: Quiero una luz indirecta detrás de esta moldura. — Хочу скрытый свет за этим молдингом.
Сергей: ¿Tienes un detalle con las medidas del perfil? — Есть узел с размерами профиля?
Дизайнер: Sí, está en la última versión del plano. — Да, в последней версии плана.
Сергей: Aquí aparece otra cota. ¿Cuál confirmamos? — Здесь другой размер. Какой подтверждаем?
Дизайнер: Confirmamos veinte centímetros desde el techo terminado. — Подтверждаем двадцать сантиметров от чистого
потолка.
Сергей: De acuerdo. Hacemos el replanteo antes de cerrar. — Хорошо. Выполним разметку до зашивки.
Заказчик: ¿Podemos cambiar ahora la posición? — Можно сейчас поменять положение?
Сергей: Podemos revisarlo con el diseñador y confirmar el efecto en el precio y el plazo. — Можем рассмотреть с
дизайнером и подтвердить влияние на цену и срок.

6. РОЛЕВОЙ СЦЕНАРИЙ И ПИСЬМЕННОЕ ПОДТВЕРЖДЕНИЕ | 45-55 МИН
Клиент хочет повторить интерьер из 3D: деревянные панели, встроенный шкаф, скрытый свет и подвесной унитаз. План и
визуализация расходятся по одной отметке. Задай пять уточняющих вопросов, запроси актуальную версию и узел,
предложи совместную разметку. Не обещай точное совпадение до проверки материалов и размеров. Затем письменно
подтверди единственное принятое изменение.

Пример письменного подтверждения. Сначала пойми, затем перескажи своими словами:
Hola. Para ejecutar esta zona necesitamos el plano actualizado, el detalle de la iluminación y la referencia del
revestimiento. Hemos detectado una diferencia entre el render y la cota del plano. Confirmamos la solución con el
diseñador antes de hacer el replanteo.
Здравствуйте. Для выполнения этой зоны нужен актуальный план, узел освещения и артикул облицовки. Обнаружили
расхождение между визуализацией и размером на плане. До разметки согласуем решение с дизайнером.

7. КОНТРОЛЬ БЕЗ ПОДСКАЗКИ | 55-60 МИН
1. Мы хотим сохранить эту дверь.
2. Вы можете подтвердить размер?
3. Нам нужен актуальный план.
4. Мы выполняем проект дизайнера.
5. Где хотите разместить раковину?
6. Мы не меняем планировку без подтверждения.
7. Этот размер взят от чистого пола?
8. Сначала делаем разметку.

8. КЛЮЧИ К КОНТРОЛЮ | ОТКРЫТЬ ПОСЛЕ ПОПЫТКИ
1. Queremos mantener esta puerta.
2. ¿Puede confirmar la medida?
3. Necesitamos el plano actualizado.
4. Ejecutamos el proyecto del diseñador.
5. ¿Dónde quiere colocar el lavabo?
6. No cambiamos la distribución sin confirmación.
7. ¿Esta medida está tomada desde el suelo terminado?
8. Primero hacemos el replanteo.

ПРОВЕРКА РЕЗУЛЬТАТА
Рабочая цель: 7 из 8 контрольных фраз без таблицы и понятный разговор по сценарию. Допустимы другие грамматически
правильные ответы с тем же смыслом. Вопрос, отрицание, участник и технический предмет должны совпадать с заданием.
При ошибке произнеси правильное предложение целиком. Итоговая оценка урока 16 дополнена собственной шкалой в
сценарии.

ПОВТОРЕНИЕ МЕЖДУ ЗАНЯТИЯМИ | 10 МИНУТ
3 минуты: три глагола в формах «я / мы / мы не / Вы...?». 4 минуты: диалог в двух ролях с заменой двух предметов. 3
минуты: объясни реальную или учебную ситуацию на объекте пятью фразами. Для прошлых событий используй прошедшие
формы после урока 14; до этого тренируй учебные ситуации в настоящем. Это дополнительное закрепление сверх 16
учебных часов.

СПРАВОЧНИК ПО ТЕМЕ | ДЛЯ ПОИСКА НА ОБЪЕКТЕ
Проект: el plano de distribución — план планировки; el plano de instalaciones — план коммуникаций; el plano de
iluminación — план освещения; el plano de acabados — план отделки; el alzado — развёртка/фасадный вид; la planta —
план этажа/этаж; el estado actual — существующее состояние; el estado reformado — состояние после ремонта; la
leyenda — условные обозначения; la referencia — артикул/ссылка; la especificación — спецификация; la ficha técnica
— техкарта; la muestra — образец; el presupuesto por partidas — смета по позициям.
Детали портфолио: la moldura — молдинг; la hornacina — ниша; la fosa de luz — ниша/карман для скрытого света; la
iluminación indirecta — отражённое скрытое освещение; el panel de listones — реечная панель; la carpintería a
medida — столярные изделия по размеру; el arco — арка; el espejo retroiluminado — зеркало с подсветкой.
Глаголы-справка: diseñar — проектировать; interpretar — интерпретировать/читать; replantear — размечать; dibujar —
чертить; proponer — предлагать; aprobar — согласовывать; autorizar — разрешать; mover — перемещать; adaptar —
адаптировать; especificar — задавать в спецификации; comparar — сравнивать; validar — подтверждать
пригодность/согласовывать.
