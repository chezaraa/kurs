# INKCRAFT — Испанский для ремонта

Готовый статический сайт: 16 уроков для общения о ремонте квартир в Барселоне, Таррагоне и на Costa Dorada.

В курсе есть карточки со свайпами, скрываемый перевод, разговоры с заказчиком, упражнения, самопроверка и конспекты. Общий справочник содержит 269 глаголов, 100 вопросов заказчика с ответами и словарные записи по материалам, инструментам и работам.

## Открыть на компьютере

Распакуйте архив целиком и откройте `index.html`. Папки `assets` и `texts` должны оставаться рядом с ним. Сайт использует обычные HTML, CSS и JavaScript: сервер, Python, Node.js, ключи и установка зависимостей для запуска не нужны.

## Разместить на GitHub Pages

1. Создайте репозиторий, например `inkcraft-spanish`. На GitHub Free для Pages нужен публичный репозиторий; возможности закрытых репозиториев зависят от тарифа.
2. Распакуйте ZIP. Загрузите **содержимое** архива в корень репозитория через **Add file → Upload files** и сохраните изменения. Загружать сам ZIP вместо файлов сайта не нужно.
3. Проверьте, что `index.html`, `assets`, `texts`, файлы `lesson-01.html`–`lesson-16.html` и `.nojekyll` находятся в корне, а не внутри дополнительной папки.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. Нажмите **Save**.
5. Откройте адрес, который появится в разделе Pages. Если основная ветка называется иначе, выберите её вместо `main`.

Официальные инструкции GitHub:

- https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
- https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Обычный сайт GitHub Pages доступен по публичной ссылке. В подготовленной версии собственной авторизации нет.

## Диалоги и озвучивание

В каждом уроке есть отдельный диалог с заказчиком: 400–525 испанских слов, примерно 4–5 минут спокойного чтения. Нажмите **Диалог ▶** в уроке или **Диалог с заказчиком** под его названием в оглавлении.

- **Слушать весь диалог** читает испанские предложения по очереди и подсвечивает текущую фразу.
- Нажатие на предложение открывает его перевод и приблизительное произношение русскими буквами с ударениями.
- Кнопка **▶** возле фразы читает только её; **Слушать диалог отсюда** продолжает разговор с выбранного места.
- Есть выбор скорости, испанского голоса, пауза и остановка. После паузы текущая фраза повторяется с начала.

Озвучивание использует Web Speech API браузера и голос устройства или его речевого сервиса. Предпочтение отдаётся es-ES. Если испанский голос недоступен, его нужно установить в настройках устройства; во встроенном браузере попробуйте открыть сайт в Safari или Chrome. При уходе с вкладки чтение ставится на паузу. Звук на заблокированном экране не гарантируется. MP3-файлов и платного API в этой версии нет.

Русская транскрипция — приблизительная учебная опора, а не точная фонетическая запись. Межзубный [θ] передан буквой «с», b/v — через «б»; сверяйтесь с озвучиванием.

## Прогресс и перенос между устройствами

Место в каждом уроке, результаты самопроверки и отметки завершения хранятся в браузере. Они не синхронизируются автоматически между устройствами или адресами сайта.

Чтобы перенести прогресс с текущей страницы курса на GitHub Pages или на другой телефон, нажмите **Сохранить прогресс** внизу оглавления. На новом адресе нажмите **Загрузить прогресс** и выберите полученный JSON-файл. Это учебный прогресс; данные учётной записи в него не включаются.

## Файлы

- `index.html` — главная страница и оболочка курса.
- `assets/app.css` — оформление.
- `assets/app.js` — навигация, словарь, карточки и самопроверка.
- `assets/learning-core.js` — логика прогресса и проверки.
- `assets/course-data.js` — материалы всех 16 уроков.
- `assets/dialogues-data.js` — 16 диалогов, переводы и произношение 585 предложений.
- `assets/dialogue.js` — интерактивный экран диалогов.
- `assets/speech-core.js` — очередь озвучивания и управление воспроизведением.
- `assets/*.jpeg` — иллюстрации из предоставленного портфолио INKCRAFT.
- `texts/lesson-01.txt`–`lesson-16.txt` — конспекты целиком.
- `lesson-01.html`–`lesson-16.html` — прямые ссылки на уроки и совместимость со старыми адресами.
- `.nojekyll` — отключение обработки Jekyll при публикации готового статического сайта.

Все пути к файлам относительные. Сайт рассчитан и на корневой адрес, и на GitHub Pages с названием репозитория в пути. Внешние библиотеки, сетевые шрифты, сбор данных и серверные API приложения не используются. Озвучивание выполняется речевым сервисом браузера; доступность и сетевые требования голоса зависят от устройства.

## Учебный материал

Основная программа — 16 занятий по 60 минут. Справочники и повторение расширяют практику сверх этого времени. Это курс профессионального общения: технические решения и оформление конкретного объекта проверяются отдельно. Цены, размеры и ситуации в упражнениях учебные.

Исходные тексты курса подготовлены 26 октября 2026 года; сайт собран 27 октября 2026 года. Даты и ссылки на официальные местные источники сохранены в соответствующих уроках и разделе «Источники и адаптация». Фотографии взяты из предоставленного портфолио INKCRAFT.
